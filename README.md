# Sol Studio downloads

This repository hosts Sol Studio binary releases, not the application source.
Download installers from https://github.com/OscarArranz/sol-studio-releases/releases.

Available platforms vary by version; see each release's listed downloads.
Initial releases are unsigned (macOS apps are ad-hoc signed, not notarized).
See each release's installation instructions and verify its SHA256SUMS.

Every version includes matching LGPL source/object-code relinking kits. Keep the
kit matching your binary; its README.txt explains library modification and relinking.
Third-party license texts and notices are also included in the installers.
